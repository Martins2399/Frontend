# TechStore - Exercício 4 (Frontend)

Projeto desenvolvido como parte prática do módulo de desenvolvimento frontend, aplicando estruturação moderna com HTML5, estilização avançada com CSS3 e Flexbox.

## Estrutura
- **index.html**: Página inicial/boas-vindas.
- **produtos.html**: Galeria de produtos com cards em grade.
- **produto-*.html**: Páginas individuais de descrição de cada item.
- **contato.html**: Página de suporte e envio de mensagens.
- **css/style.css**: Folha de estilos externa com efeitos de hover e responsividade.
