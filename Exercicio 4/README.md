# Exercício 4 - Parte 1: Estrutura Inicial da Loja Fictícia

## Descrição do Projeto
Estruturação inicial de uma loja virtual multipáginas desenvolvida em HTML5 e CSS3 externos, contendo páginas de início, listagem de produtos e formulário/seção de contato, além de diretórios dedicados para estilos e mídias.

## Estrutura de Pastas
* `index.html`: Página principal da loja.
* `produtos.html`: Página de catálogo de produtos.
* `contato.html`: Página de suporte e contato.
* `css/style.css`: Folha de estilos externa unificada.
* `img/`: Diretório reservado para imagens e mídias.
