# Sistema de Cadastro e Tarefas com Consulta CEP, APIs e SQLite - Exercício 9

## Objetivo do Projeto
O **Exercício 9** é uma aplicação web responsiva completa para gerenciamento de cadastro de usuários com busca dinâmica de CEP via API REST (ViaCEP), controle de lista de tarefas e consultas a APIs externas integradas a armazenamento local e SQLite.

## Framework Responsivo Escolhido
- **Bootstrap 5.3 (via CDN)**: Utilizado para garantir layout responsivo, formulários estilizados, grid flexível e componentes interativos (navbar, cards, modais e alertas).
