# Exercício 1 - Parte 5: Projeto Final Frontend

## 1. Objetivo do Projeto
Desenvolver um mini site web utilizando HTML5 semântico, estilização com CSS3, estruturação modular de arquivos e uma funcionalidade interativa básica em JavaScript, garantindo boas práticas de organização e documentação.

## 2. Estrutura de Pastas e Arquivos
* **`index.html`**: Arquivo principal com a marcação semântica e conteúdo da página.
* **`css/style.css`**: Folha de estilos responsável pelo design, cores e layout responsivo.
* **`js/script.js`**: Script JavaScript que gerencia o comportamento dinâmico e interativo do botão.
* **`img/`**: Pasta destinada ao armazenamento de recursos visuais e imagens do projeto (ex: `banner.png`).
* **`README.md`**: Documentação oficial explicativa sobre a construção do projeto.

## 3. Como Abrir e Executar o Projeto
1. Clone ou baixe o repositório principal em sua máquina local.
2. Abra a pasta do repositório utilizando o **Visual Studio Code (VS Code)**.
3. Certifique-se de ter a extensão **Live Server** instalada no VS Code.
4. Clique com o botão direito sobre o arquivo `index.html` localizado na pasta `Exercicio 1/Parte 5 - Projeto Final` e selecione **"Open with Live Server"**, ou abra-o diretamente em qualquer navegador web de sua preferência.

## 4. Validação e Revisão Feita
* O código HTML foi estruturado utilizando tags semânticas obrigatórias (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* Acessibilidade garantida com o uso correto do atributo `alt` na tag de imagem.
* Links externos validados com atributos de segurança (`target="_blank"` e `rel="noopener noreferrer"`).
* Validação visual e de sintaxe verificada localmente.
