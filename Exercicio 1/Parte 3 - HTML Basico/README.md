# Exercício 1 - Parte 3: Documentação das Tags HTML

Este documento explica a função de cada tag HTML utilizada no arquivo `index.html`.

## Tags Estruturais Básicas
* **`<!DOCTYPE html>`**: Declara que o documento está escrito na versão HTML5.
* **`<html>`**: Tag raiz que envolve todo o conteúdo da página web.
* **`<head>`**: Contém as configurações globais, codificação de caracteres e metadados que não aparecem na tela.
* **`<title>`**: Define o título da página exibido na aba do navegador.
* **`<body>`**: Envolve todo o conteúdo visível da página (textos, títulos, listas e imagens).

## Tags de Texto e Conteúdo
* **`<h1>`**: Representa o título principal da página, de maior hierarquia.
* **`<h2>`**: Representa subtítulos ou seções secundárias dentro do documento.
* **`<p>`**: Utilizada para definir parágrafos de texto comum.

## Tags de Listas
* **`<ul>` (Unordered List)**: Define uma lista não ordenada (exibida por padrão com marcadores/pontos).
* **`<ol>` (Ordered List)**: Define uma lista ordenada (numerada sequencialmente).
* **`<li>` (List Item)**: Define cada um dos itens individuais contidos dentro de uma lista (`<ul>` ou `<ol>`).
