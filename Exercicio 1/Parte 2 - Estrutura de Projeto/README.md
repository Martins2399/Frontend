# Exercício 1 - Parte 2: Estrutura de Projeto Web

## Explicação da Estrutura de Arquivos e Pastas

* **`index.html`**: É a página principal e o ponto de entrada de qualquer site web. Contém a estrutura e a marcação HTML de todo o conteúdo da aplicação.
* **`css/`**: Pasta destinada a armazenar todas as folhas de estilo do projeto.
  * **`css/style.css`**: Arquivo responsável por definir o design, cores, fontes, layout e a estilização dos elementos HTML.
* **`js/`**: Pasta reservada para guardar os scripts de automação e interatividade do sistema.
  * **`js/script.js`**: Arquivo com o código JavaScript que traz dinamicidade, comportamento e regras da aplicação no cliente.
* **`img/`**: Pasta destinada ao armazenamento de imagens, ícones e recursos visuais do projeto.
* **`README.md`**: Arquivo de documentação em formato Markdown, responsável por explicar a organização, o propósito e como utilizar o projeto.
