# Exercício 1 - Parte 1: Pesquisa Inicial

## 1. O que é Frontend?
O **Frontend** (ou lado do cliente) é a parte de uma aplicação web ou software que os usuários conseguem ver e interagir diretamente no navegador. Ele engloba a interface gráfica, o design, os botões, os menus e a experiência visual, sendo construído principalmente com tecnologias como HTML, CSS e JavaScript.

## 2. O que é Cliente x Servidor?
O modelo **Cliente x Servidor** é a arquitetura básica da internet:
* **Cliente:** É o dispositivo ou software (como o navegador Google Chrome ou um aplicativo no celular) que faz uma requisição de informação ou página.
* **Servidor:** É o computador potente ou sistema remoto que armazena os arquivos do site, processa as regras de negócio e devolve a resposta solicitada pelo cliente.

## 3. Qual é o papel de HTML, CSS e JavaScript?
* **HTML (HyperText Markup Language):** É a linguagem de marcação responsável por estruturar o conteúdo da página (textos, imagens, títulos, formulários).
* **CSS (Cascading Style Sheets):** É a linguagem de estilização responsável pelo design, cores, fontes, espaçamentos e pela responsividade.
* **JavaScript:** É a linguagem de programação que adiciona interatividade, dinamismo e comportamento à página (como animações e validação de formulários).

## 4. O que é W3C?
O **W3C (World Wide Web Consortium)** é a principal organização internacional de padronização da World Wide Web. Sua missão é garantir o crescimento sustentável da internet, criando padrões abertos e diretrizes para que os sites funcionem de forma igual em qualquer navegador.
