# To-Do List TaskFlow - Exercício 8

## Objetivo do Projeto
O **TaskFlow** é uma aplicação To-Do List responsiva desenvolvida para gerenciar tarefas de forma simples e eficiente. O projeto combina interface moderna, manipulação do DOM em JavaScript e persistência/armazenamento de dados com suporte a SQLite.

## Framework Responsivo Escolhido
- **Bootstrap 5.3 (via CDN)**: Escolhido por ser um framework amplamente utilizado no mercado, com excelente suporte para grid responsivo, componentes visuais prontos (navbars, cards, botões, alertas e modais) e facilidade de estilização rápida sem exigir CSS complexo do zero.

## Estrutura de Arquivos
- `index.html`: Interface principal do sistema TaskFlow.
- `assets/css/styles.css`: Estilizações customizadas exclusivas da aplicação.
- `assets/js/app.js`: Lógica principal da aplicação e manipulação do DOM.
- `assets/js/database.js`: Módulo de integração e manipulação do banco de dados SQLite.
- `database/schema.sql`: Script de criação e estrutura das tabelas do banco de dados.
