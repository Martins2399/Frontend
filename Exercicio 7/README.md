# Sistema de Cadastro de Produtos - Exercício 7

## Objetivo do Sistema
Desenvolver um sistema web responsivo para cadastro e gerenciamento de produtos de uma loja fictícia, utilizando HTML5, CSS3, JavaScript e o recurso de `localStorage` para persistência dos dados localmente no navegador.

## Estrutura de Arquivos
- `index.html`: Página inicial/boas-vindas.
- `cadastro.html`: Formulário de cadastro de novos produtos.
- `lista.html`: Tabela/listagem dos produtos cadastrados.
- `contato.html`: Formulário de suporte/contato.
- `css/style.css`: Estilos customizados complementares.
- `js/script.js`: Lógica de manipulação de dados com `localStorage`.
- `img/`: Pasta destinada a imagens do sistema.

## Framework Responsivo Utilizado
- **Bootstrap 5.3 (via CDN)**
