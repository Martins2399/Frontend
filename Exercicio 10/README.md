# Projeto Final: Dashboard de Gestão de Projetos e Tarefas (TaskMaster Pro) - Exercício 10

## Tema Escolhido
**TaskMaster Pro**: Um sistema web SPA (Single Page Application) desenvolvido em **React e Vite** para controle de projetos, gerenciamento de tarefas por prioridade, acompanhamento de prazos e métricas de produtividade em tempo real.

## Tecnologias Utilizadas
- **React 18 + Vite** (Estrutura de componentes e alta performance de build)
- **Bootstrap 5** (Framework CSS responsivo para componentes e grid)
- **CSS3 customizado** (`src/styles.css`)

1. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.
2. Abra o terminal na pasta `frontend/Exercicio 10/`.
