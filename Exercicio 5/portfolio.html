Explicação do Projeto

O projeto consiste em uma loja virtual responsiva completa (TechStore), projetada para oferecer uma experiência de navegação otimizada em múltiplos dispositivos, desde smartphones até monitores de alta resolução.

Tecnologias Utilizadas

  • HTML5 Semântico
  • CSS3 Extensivo Exclusivamente Externo
  • Git e GitHub para controle de versão

Decisões de Responsividade

  • Mobile First: Estilização inicial construída focando na experiência em telas pequenas.
  • Media Queries & Breakpoints: Implementados em 768px (Tablets) e 1024px (Desktops).
  • CSS Grid & Flexbox: Uso de CSS Grid para a galeria flexível de produtos (1, 2 e 3 colunas) e Flexbox para cabeçalho e formulários.
  • Menu Responsivo: Menu hambúrguer funcional utilizando controle por `checkbox` sem dependência de JavaScript.
