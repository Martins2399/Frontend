# Loja Responsiva - Exercício 5 (TechStore)

## Objetivo do Projeto
Desenvolver uma loja virtual fictícia totalmente responsiva utilizando HTML5 e CSS3 externo, seguindo a metodologia Mobile First, com suporte a múltiplos dispositivos por meio de Media Queries, CSS Grid e Flexbox.

## Lista de Páginas
- `index.html`: Página inicial com mensagem de boas-vindas e chamada para a loja.
- `produtos.html`: Galeria responsiva contendo os cards de produtos.
- `produto-notebook.html`: Detalhes do produto Notebook Start.
- `produto-fone.html`: Detalhes do produto Fone Air.
- `produto-smartwatch.html`: Detalhes do produto Smartwatch Fit.
- `produto-camera.html`: Detalhes do produto Câmera Mini.
- `produto-mochila.html`: Detalhes do produto Mochila Tech.
- `portfolio.html`: Apresentação do aluno, explicação do projeto e decisões técnicas de responsividade.
- `contato.html`: Formulário de contato para suporte e dúvidas.
